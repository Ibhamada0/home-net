# خطة: برنامج محلي بدون سيرفر وبدون كلاود

## الفكرة
كل شغل التطبيق يبقى داخل المتصفح على جهازك. البيانات تتخزن في IndexedDB (قاعدة داتا داخل المتصفح)، والاتصال بالراوتر يتم عن طريق البروكسي المحلى الصغير اللى عملناه.

```text
المتصفح (PWA)        جهازك              الراوتر
+----------------+   +-------------+   +---------+
| IndexedDB      |   | proxy.mjs   |   | REST API|
| Local data     |<->| localhost   |<->| MikroTik|
| Service Worker |   | :8080       |   |         |
+----------------+   +-------------+   +---------+
```

## المميزات
- لا كلاود، لا Supabase، لا سيرفر داتابيز.
- يشتغل اوفلاين بعد أول فتح (PWA).
- الراوتر على نفس الشبكة بس.
- البروكسي مجرد موصل، مش سيرفر حقيقي (بدون داتابيز، بدون منطق).

## الخطوات

### 1) بنية قاعدة البيانات المحلية
استخدام `Dexie.js` أو `idb` لتخزين كل الجداول المحلية:
- `customers`
- `packages`
- `subscriptions`
- `invoices`
- `payments`
- `traffic_usage`
- `blocked_domains`
- `users` (للتسجيل الدخول المحلى)
- `settings` (إعدادات الراوتر + البروكسي)

### 2) إدخال طبقة Local DB
عمل hook/utility موحد `src/lib/db.ts` يستبدل كل `supabase.from(...)` في:
- صفحات العملاء
- الباقات والاشتراكات
- الفواتير والمدفوعات
- الاستهلاك والحظر
- صفحة الإعدادات

### 3) تسجيل الدخول المحلى
بدل Supabase Auth:
- username/password مخزنين محلياً ومشفّرين (bcrypt.js على المتصفح).
- دور افتراضي واحد `admin`.
- لو مش عايز كلمة سر، يمكن تفعيل "دخول تلقائى" بعد أول مرة.

### 4) المزامنة مع الراوتر
الزر "مزامنة من الراوتر" يستخدم البروكسي المحلى زى ما هو (`http://localhost:8080`) ويحفظ النتيجة فى IndexedDB.

### 5) PWA (offline)
- إضافة `manifest.json` + `service worker` يخزن الـ assets.
- بعد أول فتح، التطبيق يفتح من الـ cache لو مش متصل بالنت.

### 6) Backup / Restore (اختيارى)
زر "تصدير" ينزل كل الداتا ملف JSON، وزر "استيراد" يرجّعها.

### 7) Migration من الكلاود (اختيارى)
لو عندك داتا على Supabase دلوقتى، نعمل صفحة/أداة لمرة واحدة تسحب كل الجداول وتخزنها فى IndexedDB.

## التشغيل
1. شغّل البروكسى: `node local-proxy/proxy.mjs`
2. شغّل التطبيق: `npm run dev` (أو `npm run build` + static server)
3. افتح `http://localhost:5173` واستخدمه عادى.

## التأثير
- يتم حذف/تعطيل كل ملفات Supabase تدريجياً.
- كل شيء يصبح محلى 100% ما عدا البروكسي الصغير.

## سؤال واحد قبل البدء
هل عايز تبدأ بـ داتا جديدة فاضية، ولا عايز نسحب الداتا الموجودة على الكلاود الأول؟
- **A:** داتا جديدة (أسرع وأسهل).
- **B:** اسحب داتا Supabase الحالية (هنحتاج نعمل migration لمرة واحدة).
